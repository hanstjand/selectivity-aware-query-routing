\section{Conclusion}
\label{sec:conclusion}

Routing each filtered query by a histogram-based row estimate and one calibrated threshold met the quality targets on
held-out queries and cut p50 latency by 45\% and p95 by 80\% relative to the best fixed strategies, close to a
hindsight oracle. Future work should cover categorical and multi-attribute filters, larger collections, concurrent
workloads, and a planner cost model that accounts for result completeness.
